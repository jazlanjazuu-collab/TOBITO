# Online Store Website

This is a beginner-friendly online store website project.

## Features
- Website-only order system
- Order collection using Google Forms
- Admin panel using Google Sheets
- Cash on Delivery (COD) supported
- Manual order fulfillment through a trusted delivery partner
- Delivery status update system

## How Orders Work
1. Customer places an order on the website
2. Order details are saved in Google Forms
3. Admin manages orders using Google Sheets
4. Order is placed with the delivery partner
5. Product is delivered to the customer

## Tech Used
- HTML & CSS
- Google Forms
- Google Sheets
- GitHub Pages (Free hosting)

## Note
This project is intended for learning and small-scale online selling.
No payment gateway or marketplace API automation is used.
